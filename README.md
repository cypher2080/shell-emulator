# Эмулятор командной оболочки (вариант №2)

Практическая работа №1 по дисциплине «Конфигурационное управление».

## Общее описание

Консольный эмулятор языка оболочки UNIX-подобной ОС. Приложение
работает в режиме REPL: читает строку, разбирает её на команду и
аргументы, выполняет команду и печатает результат. Реализовано на
Python 3 без внешних зависимостей.

Текущий этап: **Этап 2. Конфигурация** — добавлены параметры
командной строки и стартовые скрипты. Команды `ls` и `cd` являются
заглушками.

Структура репозитория:

```
src/            исходный код
tests/          модульные тесты
tests/data/     образы VFS
tests/scripts/  скрипты ОС (*.sh) и стартовые скрипты эмулятора (*.vsh)
run.sh          скрипт запуска
```

## Описание функций и настроек

### Приглашение к вводу

Приглашение формируется на основе реальных данных ОС, в которой
запущен эмулятор: `username@hostname:~$`.

### Парсер

Строка разделяется на команду и аргументы по пробелам. В аргументах
раскрываются переменные окружения реальной ОС, например `$HOME`.
Неизвестная переменная раскрывается в пустую строку.

### Параметры командной строки

| Параметр | Описание |
| --- | --- |
| `--vfs ПУТЬ` | путь к физическому расположению VFS |
| `--script ПУТЬ` | путь к стартовому скрипту |

При запуске эмулятор печатает отладочный вывод заданных параметров:

```
[debug] vfs    = tests/data/vfs_min.json
[debug] script = tests/scripts/stage2_basic.vsh
```

### Стартовый скрипт

Стартовый скрипт (`*.vsh`) содержит команды эмулятора, по одной в
строке; пустые строки пропускаются. При выполнении на экран выводится
как ввод (с приглашением), так и вывод, что имитирует диалог с
пользователем. При первой же ошибке выполнение скрипта
останавливается, эмулятор сообщает об этом и завершается с кодом 1.

### Команды

| Команда | Описание |
| --- | --- |
| `ls [аргументы]` | заглушка: печатает имя команды и аргументы |
| `cd [путь]` | заглушка: печатает имя команды и аргументы |
| `exit [код]` | завершение работы эмулятора |

### Обработка ошибок

Ошибки не прерывают работу эмулятора и выводятся строкой
`ошибка: <описание>`:

* `<имя>: команда не найдена` — неизвестная команда;
* `cd: слишком много аргументов` — неверные аргументы `cd`;
* `exit: требуется числовой аргумент` — неверный код выхода;
* `не удалось прочитать скрипт: ...` — стартовый скрипт не найден;
* `<путь>: строка N: выполнение остановлено` — ошибка в скрипте.

## Сборка и запуск

Сборка не требуется, нужен только Python 3.

```bash
./run.sh
```

Запуск тестов:

```bash
python3 -m unittest discover -s tests
```

Запуск с параметрами:

```bash
./run.sh --vfs tests/data/vfs_min.json --script tests/scripts/stage2_basic.vsh
```

Демонстрация всех возможностей прототипа, включая обработку ошибок:

```bash
sh tests/scripts/stage1_demo.sh
```

Скрипты ОС: все сочетания параметров командной строки и ошибки
стартового скрипта:

```bash
sh tests/scripts/stage2_params.sh
```

```bash
sh tests/scripts/stage2_errors.sh
```

## Примеры использования

```
user@host:~$ ls -l /etc
ls -l /etc
user@host:~$ cd /home/user
cd /home/user
user@host:~$ ls $HOME
ls /home/user
user@host:~$ nosuchcommand arg
ошибка: nosuchcommand: команда не найдена
user@host:~$ cd a b
ошибка: cd: слишком много аргументов
user@host:~$ exit now
ошибка: exit: требуется числовой аргумент
user@host:~$ exit
```

### Выполнение стартового скрипта

```
$ ./run.sh --script tests/scripts/stage2_error.vsh
[debug] vfs    = <не задан>
[debug] script = tests/scripts/stage2_error.vsh
user@host:~$ ls ok
ls ok
user@host:~$ nosuchcommand arg
ошибка: nosuchcommand: команда не найдена
ошибка: tests/scripts/stage2_error.vsh: строка 2: выполнение остановлено
```
